## 💰 滿額現折機制（全館，回饋無上限）

> 4/1 改版後的主力優惠機制，**取代了舊的點數折抵**。

| 訂單金額 | 折抵金額 |
| --- | --- |
| 滿 NT$30,000 | 折 NT$3,000 |
| 滿 NT$40,000 | 折 NT$4,000 |
| 滿 NT$50,000 | 折 NT$5,000 |
| 每增加 NT$10,000 | 加折 NT$1,000 |

- 等同回饋率 **10%**，**無上限**
- 範例：消費 NT$100,000 → 自動現折 NT$10,000
- **出清品除外**（絕版出清品不適用滿額折）

## 🪙 購物金規則（取代舊點數）

> ⚠️ AI 必須使用「購物金」而非「點數」字眼

### 規則
- 1 點購物金 = **NT$1 元新台幣**
- 每筆訂單最高可使用購物金折抵 **8%**
- 可疊加滿額現折使用
- **無有效期限**（不會過期）

### 既有點數的轉換
- 原會員既有點數已由系統 **自動轉為購物金**
- 1 點原點數 = 1 點購物金
- 顧客無需手動兌換，登入即可使用

## ⚙️ 與 Shopline API 的對接

### 查會員（cs-shopline.query_customer）
從 Shopline 取得：
- `total_spent` → 推算海獺等級
- `tags` → 可能有等級標籤
- 購物金餘額 → [請補：Shopline API 是否提供購物金欄位？或需另查 wallet endpoint]

### 海獺等級判斷邏輯
```python
if total_spent < 80001:
    tier = "初入島的海獺"
elif total_spent <= 120000:
    tier = "睡薄墊的海獺"  # 終身 96 折
else:
    tier = "癱 LOVEFU 床的海獺"  # 終身 94 折
```
