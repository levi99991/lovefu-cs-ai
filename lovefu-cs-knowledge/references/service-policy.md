## 💤 安心睡計畫

安心睡計畫是 LOVEFU 承諾的舒適睡眠體驗保障。

### 各品項天數
| 產品 | 安心睡天數 | 起算 |
| --- | --- | --- |
| 獨立筒床墊（山丘 / 冰島 / 飄雲） | **100 天** | 物流簽收當日，含假日 |
| 月眠枕 3.0 | **15 天** | 同上 |
| 無光薄墊 | **30 天** | 同上 |
| 無光厚墊 | **30 天** | 同上 |
| **邊框加固版床墊** | ❌ **無安心睡** | — |
| **IKEA & MUJI 尺寸床墊** | ❌ **無安心睡** | — |
| **絕版出清品** | ❌ **無安心睡** | — |
| **客製尺寸** | ❌ **無安心睡** | — |

### 適用條件
- 同一人首次購買時，可享有一次安心睡計畫
- 第二次購買同樣商品，不再享有
- 商品須套上枕頭套/床包使用，確保原既定樣貌
- 避免髒污、過多毛球及破損等人為因素

### 退貨必備清單（缺件無法辦理）
| 產品 | 必備物品 |
| --- | --- |
| 獨立筒床墊 | 原塑膠袋 + 保固卡（使用&保固手冊） |
| 月眠枕 3.0 | 原紙箱 + 原塑膠袋 + 枕頭棉布提袋 + 枕頭說明卡 |
| 無光床墊 | 原紙箱 + 原塑膠袋 + 保固卡（使用&保固手冊） |

→ **塑膠袋遺失**：可自行支付費用，司機收件時攜帶包裝材料前往。

### 退貨運費
- **床墊類**：NT$1,500 / 件，由顧客負擔
- **枕頭 / 寢飾 / 小件配件**：[請補：運費金額——$1,500 是床墊費率，小件應較低]
- 偏遠地區退貨：另加偏遠地區費用（客人負擔）
- 請保留包裝並搭配床包使用
- ⚠️ AI 報退貨運費時，床墊用 $1,500；小件未確認前 → 「退貨運費我幫你跟輔睡員確認一下」

## 🚚 配送

### 物流商（2026-05 現況：僅森森物流）
> ⚠️ **目前合作中的物流只有「森森物流」**。先前的賀盟（跑得快）、嘉里大榮、職人等**都已停止合作**，舊資料勿用。

- **森森物流**：負責**大型寢具**（床墊、無光薄墊、無光厚墊）配送
  - 可指定日期、不可指定時段
  - 偏遠地區需另外報價（內部流程：上傳地址到森森群組 @森哥 詢問報價）
- **霧峰倉合作廠商**：負責**小件**（枕頭、寢飾、配件）出貨
  - 由霧峰倉的合作物流廠商配送
  - [請補：合作廠商名稱、配送天數、是否可指定日期]

### 森森物流配送排程（依地區，週一公休）
| 地區 | 配送日 |
| --- | --- |
| 北北桃（台北/新北/桃園）| 週二 ~ 週日 |
| 淡水 | 週二 ~ 週五（假日不進）|
| 基隆 | 週二 ~ 週五（假日不進）|
| 新竹苗栗 | 週二 ~ 週日 |
| 雲嘉南高屏 | 週三、週日為主，週四、週六為輔 |
| 中彰投 | 週三、週六為主，週日為輔 |
| 宜蘭 | 週五 |
| 花東 | 每月中擇 1~2 天 |

### 床墊製作與出貨
- **製作工時**：下單後 14~30 個工作天（不含假日）
- **現貨情況**：如有現貨約 7~10 個工作天出貨
- **指定日期注意**：請壓「兩天後」的日期，勿壓當天及隔天；實際依森森各地區配送日

### 配送流程
1. 製作完畢／現貨備齊 → 森森物流安排配送
2. 收件人地址依地區排入森森配送日
3. 偏遠地區先報價確認再配送
- **搬運**：搭電梯免費搬上樓（需定位/管理室代收/搬下樓可在訂單備註）
- **包裝**：捲包床壓縮出貨，拆封時小心回彈反作用力

### ⚠️ AI 對話注意
- 顧客問「能不能指定時段」→ **只能指定日期不能指定時段**，誠實告知
- 顧客問「我這地區哪天會送」→ 依上方森森配送排程回答（週一公休）
- 偏遠地區 → 「你的地址可能需要另外確認配送安排，我幫你轉輔睡員報價」
- **偏遠地區安心睡退貨**：客人須負擔床墊退貨費用 **+ 偏遠地區費用**（要主動提醒）

### 樓層費（重要）
- **NT$100 / 床 / 層**（爬樓梯時）
- 現場給司機師傅
- 俗稱「茶水費」

### 一般商品
- 全店滿 NT$1,500 免運
- 床墊、家具皆贈送免運費

### 舊床回收
- **目前不提供**
- 師傅可協助搬下樓，但仍計樓層費

## 🛡️ 保固

### 獨立筒床墊保固標準
- **泡棉**：3 年保固 / 5 年保修
- **獨立筒彈簧**：10 年保固
- **泡棉凹陷判斷**：超過原始厚度 25% 屬不正常塌陷 → 可保固更換
  - 範例：撐腰樂眠床泡棉 5cm，凹陷超過 1.25cm 就算不正常
- **正常現象**：獨立筒和泡棉使用後略微回軟約 10%

### 月眠枕 3.0
- **枕芯**：5 年保固（不變形）

### 無光床墊系列
- **泡棉**：3 年保固 / 5 年保修

### 不在保固範圍
- 人為外力造成的損壞
- 不當使用造成的損壞
- 未依建議保養方式造成的損壞
- 表層自然壓痕（屬正常物理現象）

### 保固流程
- 檢測後達保固標準 → 協助更換
- 未達保固標準 → 酌收送回運費

## 🔄 退換貨 AI 輔睡員處理流程

AI 只負責「**受理**」不負責「**執行**」。
退換貨爭議涉及金額或情緒升溫 → **必須轉接人工**（見 escalation-rules.md）

### Step 1：確認類型
- 安心睡計畫退貨（試睡不滿意）
- 7 天鑑賞期退貨（一般商品）
- 商品瑕疵換貨
- 保固申請

### Step 2：收集資訊
- 訂單編號
- 購買人姓名 / 手機
- 退換貨原因
- 商品狀態（包裝是否完整）
- 瑕疵狀況（請拍照）

### Step 3：確認條件
- 配件是否齊全（對照上方必備清單）
- 是否在期限內
- 是否為首次購買
- 是否為「無安心睡」品項（加固版 / IKEA-MUJI / 客製 / 出清）

### Step 4：提交人工
- 打包資訊轉交後台人員
- 回覆話術：「已經幫你提交退換貨申請了，輔睡員會在 1~2 個工作天內跟你聯繫安排後續。有什麼問題隨時跟我說！」

### Step 5：AI 持續陪伴
- 顧客若再傳訊息 → AI 可回覆一般問題
- 不重複提交申請（避免重複建立工單）
- 涉及進度查詢 → 轉人工或引導耐心等待

### 退刷／退款的內部流程（AI 不執行，但要知道「為什麼要等」）
退款/退刷是**多層簽核的人工流程**，AI 絕不碰，但可向顧客說明「需要一點時間」：
1. 客服確認網店退換貨表單可退款
2. 上 NEUIP 系統填電子表單
3. 依付款方式分流：
   - 銀行轉帳 / 超商 / 超過退刷期限 → **退貨退款**
   - LinePay / 信用卡一次 / 信用卡分期（退刷期限內）→ **退貨退刷**
4. 主管簽核 → 執行長簽核
5. 提供紙本給會計執行

→ AI 對顧客的話術：「退款的部分需要經過內部審核流程，輔睡員會幫你申請並追蹤進度，完成後會通知你～」（不承諾具體天數）
→ 顧客退款金額計算涉及**購物金、會員折抵、活動價差** → 一律人工計算，AI 不試算
